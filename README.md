
# AURELIS
Experimental AI-based chest X-ray classification research prototype.

## Model
ResNet-18 using transfer learning.

## Dataset
Kaggle: paultimothymooney/chest-xray-pneumonia

## Independent Test Results
Accuracy: 83.01%
Precision: 79.22%
Recall: 98.72%
F1 Score: 87.90%

## Limitations
This is an experimental research prototype.
It is not a medical device and has not been clinically validated.
It must not be used for diagnosis or treatment decisions.
Dataset performance does not establish real-world clinical safety.

Our live project: https://aurelis-pfr1.onrender.com
